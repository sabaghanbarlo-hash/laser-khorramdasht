# مرکز لیزر آرامیس — سایت رزرو آنلاین

سایت رزرو نوبت آنلاین برای مرکز لیزر موهای زائد در خرمدشت، کرج. فرانت‌اند به‌صورت استاتیک (HTML/CSS/JS بدون build step) روی GitHub Pages اجرا می‌شود و داده‌ها (خدمات، نوبت‌ها، ساعات کاری) در Supabase (پایگاه‌داده Postgres رایگان) ذخیره می‌شوند.

## چرا Supabase؟

- **رایگان** برای این حجم از پروژه (پلن Free: تا ۵۰۰ مگابایت دیتابیس و ۵۰ هزار کاربر احراز هویت در ماه — بسیار بیشتر از نیاز این سایت).
- امکان اتصال مستقیم از جاوااسکریپت مرورگر بدون نیاز به سرور بک‌اند جداگانه.
- **جلوگیری از رزرو دوباره** با یک محدودیت یکتا (`unique constraint`) روی تاریخ+ساعت در پایگاه‌داده — اگر دو نفر همزمان یک ساعت را بزنند، دومی با پیام خطا مواجه می‌شود.
- سیستم Auth داخلی برای ورود مدیر.
- محدودیت: پروژه‌های رایگان Supabase بعد از ۷ روز عدم استفاده به‌صورت خودکار Pause می‌شوند (به‌راحتی از پنل Supabase دوباره فعال می‌شود).

اطلاعات پروژه Supabase که برای شما ساخته شد:
- Project ref: `vtlqybplqmosqgdimnio`
- URL: `https://vtlqybplqmosqgdimnio.supabase.co`
- کلید Anon (Public) در فایل `js/config.js` قرار دارد و نیازی به مخفی‌سازی ندارد (طراحی امنیتی Supabase بر پایه Row Level Security است، نه پنهان بودن این کلید).

## ساختار فایل‌ها

```
index.html      صفحه اصلی + سیستم رزرو (Modal چندمرحله‌ای)
admin.html      پنل مدیریت
css/style.css   استایل عمومی سایت
css/admin.css   استایل پنل مدیریت
js/config.js    آدرس و کلید Supabase
js/site.js      رفتار عمومی سایت (منو، FAQ، بارگذاری خدمات)
js/booking.js   منطق کامل رزرو نوبت
js/admin.js     منطق پنل مدیریت
robots.txt, sitemap.xml   تنظیمات سئو
```

## راه‌اندازی حساب مدیر (یک‌بار، ضروری)

پنل مدیریت هنوز هیچ کاربری ندارد. برای ساخت اولین حساب مدیر:

1. وارد https://supabase.com/dashboard/project/vtlqybplqmosqgdimnio شوید (با همان حسابی که Composio/GitHub شما به آن وصل است).
2. از منوی سمت راست: **Authentication → Users → Add user → Create new user**.
3. ایمیل و رمز عبور دلخواه را وارد کنید و **Auto Confirm User** را فعال کنید.
4. با همین ایمیل و رمز در `admin.html` وارد شوید.

می‌توانید بعداً کاربران بیشتری هم از همین مسیر اضافه کنید.

## اجرای محلی (Localhost)

چون سایت کاملاً استاتیک است، نیازی به نصب یا build ندارد. کافی است یک سرور ساده استاتیک اجرا کنید:

```bash
cd laser-khorramdasht
python3 -m http.server 8080
```

سپس در مرورگر: `http://localhost:8080`

## Deploy (GitHub Pages)

1. به تنظیمات ریپازیتوری در گیت‌هاب بروید: **Settings → Pages**.
2. در بخش **Source**، شاخه `main` و پوشه `/ (root)` را انتخاب کنید و **Save** بزنید.
3. بعد از چند دقیقه، سایت روی این آدرس در دسترس است:
   `https://sabaghanbarlo-hash.github.io/laser-khorramdasht/`

### اتصال دامنه اختصاصی و HTTPS

اگر دامنه دلخواه (مثلاً `laserkhorramdasht.com`) دارید:

1. در تنظیمات DNS دامنه، یک رکورد `CNAME` به `sabaghanbarlo-hash.github.io` اضافه کنید.
2. در **Settings → Pages → Custom domain** همان دامنه را وارد کنید.
3. گزینه **Enforce HTTPS** را فعال کنید (گیت‌هاب گواهی SSL را رایگان و خودکار صادر می‌کند).

## مدیریت روزمره

- **تغییر قیمت‌ها یا توضیحات خدمات:** admin.html → تب «خدمات» → ویرایش.
- **افزودن خدمت جدید:** admin.html → تب «خدمات» → «+ سرویس جدید».
- **تغییر ساعات کاری:** admin.html → تب «ساعات کاری».
- **تعطیل کردن یک روز خاص:** همان تب، بخش «بستن یک تاریخ خاص».
- **مسدود کردن یک بازه ساعتی مشخص:** همان تب، بخش «مسدود کردن بازه ساعتی».
- **مشاهده/تغییر وضعیت نوبت‌ها:** تب «نوبت‌ها».

همه این تغییرات مستقیماً در پایگاه‌داده ذخیره می‌شوند و نیازی به Deploy دوباره سایت نیست.

## Backup پایگاه‌داده

از پنل Supabase: **Database → Backups**. پلن رایگان بکاپ‌های روزانه‌ی ۷ روز اخیر را نگه می‌دارد. برای اطمینان بیشتر، هر چند وقت یک‌بار می‌توانید از **Database → Backups → Download** یک نسخه دستی هم بگیرید.

## نکات مهم برای راه‌اندازی نهایی کسب‌وکار واقعی

قبل از اینکه سایت را به مشتریان واقعی معرفی کنید، این موارد را تکمیل کنید:

1. **شماره تماس واقعی مرکز** — از admin.html → «ساعات کاری» → «تنظیمات نمایش عمومی» وارد کنید (روی سایت نمایش داده می‌شود).
2. **شماره طبقه دقیق ساختمان** — در حال حاضر `index.html` این بخش را با متن «در انتظار تأیید نهایی» علامت زده؛ در فایل `index.html` عبارت مربوطه را جستجو و اصلاح کنید.
3. **قیمت نواحی مختلف (صورت، زیر بغل، دست، پا، بیکینی، شکم، کمر)** — قیمت‌های فعلی تخمینی و placeholder هستند؛ از پنل مدیریت اصلاحشان کنید.
4. **پیامک تأیید نوبت (SMS)** — در نسخه فعلی پیاده‌سازی نشده (نیاز به یک سرویس پیامکی ایرانی و هزینه دارد)؛ کد به‌گونه‌ای نوشته شده که بعداً به‌راحتی می‌توان یک تابع ارسال پیامک بعد از ثبت موفق نوبت (در `js/booking.js`، داخل تابع `submitBooking`) اضافه کرد.
5. **لوگو و تصاویر واقعی مرکز** — در حال حاضر به‌جای عکس، یک تصویر انتزاعی SVG در Hero استفاده شده. هر زمان عکس واقعی داشتید، می‌توان به‌راحتی جایگزین کرد.
6. عکس، گواهی، یا نظر مشتری جعلی در سایت قرار داده نشده — طبق درخواست شما.

هر کدام از این موارد را که آماده کردید، بگویید تا برایتان به‌روزرسانی کنم.
